# KP-S8-1｜隱藏層＝非線性特徵生成器

> **一句話**：**神經網路隱藏層本質上在做「非線性特徵生成」**——把原始輸入變成新特徵，再交給輸出層分類。隱藏層神經元數 = 學到的特徵數。

> **生活類比**（組隊分工的類比）：傳統 ML 是「你（人）選特徵」→ 交給分類器。神經網路是「**助手自己學特徵**」——隱藏層像聰明助手，**自己找出**該用哪些特徵描述這批物品，輸出層只負責最後「分門別類」。
> **對應理由**：輸入 = 原始資料、隱藏層 = 自動選特徵的助手、輸出層 = 分類器。**NN 把「特徵工程」和「分類」合在一起學**——傳統要兩步，NN 一步完成。

> **公式拆解**：單個神經元 $y = f(\sum w_i x_i + b)$——$f$ 是非線性激活（sigmoid、ReLU、tanh）。多層堆疊 = **嵌套的線性 + 非線性變換**。兩層網路 + 足夠多神經元可逼近任何函數（萬能逼近定理）。

> **數值演算**：MNIST 手寫數字（$N=60000$, $l=784$ 像素）：
> - 傳統 HOG/SIFT → 50 特徵 → 線性分類器 → 95%
> - 簡單 NN：784 → 100 隱藏 → 10 輸出（**10 萬參數**）→ 98%
> 隱藏層學的 100 維特徵是「人眼無法命名、但機器能分的非線性組合」——NN 取代手工特徵工程的關鍵。

> **主動回想**：隱藏層神經元數 = 特徵數——太多會怎樣？（呼應 Peaking——神經元太多、參數遠多於 $N$，會過擬合。站 1 的 $l \approx N/\alpha$ 經驗同樣適用深度學習，只是 $\alpha$ 更大 10–50。）

> **口訣**：「**隱藏層 = 自動特徵工程師。**」

> **常見誤解**：很多學生以為「隱藏層神經元越多越好」——不是。**太多神經元 = 過擬合**（呼應 Peaking 站 1）。深度學習能突破 Peaking 是因為**資料量 N 巨大**（ImageNet 百萬級），不是因為避開 Peaking 現象。資料不夠多、神經元少一點反而更好。
