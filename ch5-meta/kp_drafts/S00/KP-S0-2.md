# KP-S0-2｜選特徵的共同目標

> **一句話**：所有特徵選擇方法都追求同一件事——**類間距離大、類內變異小**。好特徵讓不同類的特徵值離得遠、同類的聚得近。

> **生活類比**（餐廳分流的類比）：兩家餐廳（$\omega$1 義式、$\omega$2 日式）開在同一條街上，目標是兩家各自的常客範圍盡量不重疊（類間大）、每家自己的常客集中（類內小）。
> **對應理由**：常客 = 資料點、餐廳 = 類別、選位置 = 選特徵。「**類間大、類內小**」正是選位置的目標——讓兩家餐廳的常客分布明顯分開。

> **公式拆解**：這個目標沒有單一公式，但所有準則都圍繞它展開——
> - 散佈矩陣 $J_3 = \operatorname{trace}\{S_w^{-1} S_m\}$：$S_w$（類內）越小、$S_m$（總體）越大 → 越大越好
> - Fisher 判別比 $\mathrm{FDR} = (\mu_1-\mu_2)^2/(\sigma_1^2+\sigma_2^2)$：分子大、分母小 → 越大越好
> 共通邏輯——**「分子拉開、分母收緊」**。

> **數值演算**：用 Example 5.5 的三種分布對照：
> - 情況 a：類內變異小、類間距離小 → $J_3 = 164.7$
> - 情況 b：類內變異大、類間距離小 → $J_3 = 12.5$（最差）
> - 情況 c：類內變異小、類間距離大 → $J_3 = 620.9$（最佳）
>
> 用餐廳位置說：a 兩家餐廳都在同條街但各自常客很集中；b 同條街但常客散亂；c 一家在東、一家在西且常客集中。$J_3$ 排序 620.9 > 164.7 > 12.5 印證「拉開 + 收緊」。

> **主動回想**：特徵 X 類內小、類間大；特徵 Y 類內極小、類間中等。選哪個？或合併成 2 維？（提示：合併通常比單看 X 或 Y 都好——Fisher LDA 想把多個維度「壓成一條最能分的線」，站 6 詳解。）

> **口訣**：「**類間拉開、類內收緊；分子大、分母小。**」

> **常見誤解**：很多教科書把這個目標寫得很抽象——底層直覺其實很簡單：**「兩群東西要分得開」**。所有公式都是把這個直覺量化而已。
