# KP-S4-2｜J3 準則與 Example 5.5（164.7 / 12.5 / 620.9）

> **一句話**：$J_3 = \operatorname{trace}\{S_w^{-1} S_m\}$ 把三個散佈矩陣壓成一個數字——**$J_3$ 越大、類別越能分**。Example 5.5 用三種 2D 分布算出 $J_3 = 164.7 / 12.5 / 620.9$。

> **生活類比**（搬家後評估可分離度）：三對家人搬家後，問「誰家最好分」——
> - a：打包好（$S_w$ 小），門口隔 1 公尺（$S_b$ 小）→ 難分
> - b：散亂（$S_w$ 大），門口隔 1 公尺 → 最難分
> - c：打包好，門口隔 10 公尺 → 最好分
> **對應理由**：家人 = 類別、打包整齊度 = $S_w$ 反比、門口距離 = $S_b$ 開根號。$J_3$ 對應 c > a > b——**「拉開 + 收緊」雙重訴求**。

> **公式拆解**：$J_3 = \operatorname{trace}\{S_w^{-1} S_m\}$
> - $S_w^{-1}$：把類內散佈當「單位」、度量其他方向的拉伸
> - $S_m$：總體散佈
> - $\operatorname{trace}$：對角線元素和
> **$J_3$ 大 = 類間遠、類內緊**。

> **數值演算**：Example 5.5 三種 2D 分布（兩類同點數）：
> - a 類內緊（$\sigma=0.3$）、類間近（差 0.5）→ $J_3 = 164.7$
> - b 類內散（$\sigma=2.0$）、類間近（差 0.5）→ $J_3 = 12.5$
> - c 類內緊（$\sigma=0.3$）、類間遠（差 3.0）→ $J_3 = 620.9$
> 排序 c > a > b，差距 50 倍——「拉開 + 收緊」雙重訴求。

> **主動回想**：b 的 $\sigma$ 從 2.0 降到 0.3（但類間距仍 0.5），$J_3$ 變成？跟 a 差多少？（提示：$\sigma$ 同、距同 → 應等於 a 的 164.7。b「難分」是兩因素都差，**不是單一因素**。）

> **口訣**：「**$J_3$ 大 = 拉開+收緊；620.9 > 164.7 > 12.5。**」

> **常見誤解**：很多學生看到 $S_w^{-1}$ 就想「反矩陣 = 倒數」——其實**反矩陣不是逐元素倒數**，是線性代數意義下的反運算。在這裡 $S_w^{-1}$ 的作用是**把 $S_w$ 的方向「拉直」**，讓 $S_m$ 在被拉直的方向上計算拉伸。
